# ORBIT

Every feeling has a universe. A Class 12 CBSE AI project.

**Create** turns an idea into a creative universe (palette, fonts, moodboard, music, creators).
**Feel** has check-ins, a chat, Calm Room, stress-buster games, Reach Out, letters and a safety plan.

Run it:

```
pip install -r requirements.txt
streamlit run app.py
```

Files: app.py (menu), ai.py (emotion model), safety.py, database.py, replies.py, creative.py + create.py (Create), feel.py (Feel), galaxy.py (journal), about.py (AI Lab, settings).

ORBIT is an AI, not a therapist. In India, Tele-MANAS 14416 is free and open 24/7.
